이진트리 : 트리 (tree) 자료구조는 나무를 거꾸로 뒤집어 놓은 형태
트리 자료 구조 용어
부모 노드,자식 노드,루트,차수,리프노드

이진트리 예시
-모든 노드의 자식이 최대 2개인 트리
(자식이 2개이하로 구성)
-전형적인 이진 트리
루트의 오니쪽 서브 트리, 루트의 오른쪽 서브 트리

이진 트리 종류
1. 포화 이진 트리
-모든 라벨이 노드로 꽉찬 트리
-마지막 레벨까지 빈 공간이 없음

2. 완전 이진 트리
-마지막 레벨을 제외한 모든 레벨이 차 있음
-마지막 레벨은 왼쪽부터 순서대로 채워짐
-힙 자료구조에 사용됨

3. 정 이진 트리
-모든 노드가 자식 노드를 0개 혹은 2개를 가짐
-자식이 한개인 노드는 없음

4. 편향 이진 트리
-모든 노드가 왼쪽 또는 오른쪽 한방향으로만 연결됨
-연결 리스트와 비슷한 형태

5. 균형 이진 트리
-왼쪽과 오른쪽 서브트리의 높이 차이가 일정 기준 이하인 트리
-탐색효율을 높이는데 사용
